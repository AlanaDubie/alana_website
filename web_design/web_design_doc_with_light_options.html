Design Doc · Rank 02 & Rank 03 · + Light Variants

Muted Cyan & Harbor Teal

Typography, type hierarchy, and spacing specs applied on top of the two runner-up palettes from Color Test v4. Same Fraunces / Space Grotesk pairing and 2px radius system as the primary doc — only the bg, surface, and accent values change between sections below. Two light "sand" background options are included at the end — same ink and accent, only the background hex differs.

6.57:1 — comfortably clears AA, the calmest of the three passing accents. Reads as a slightly greener, more desaturated teal vs the rank 01 cyan. Dark text on the accent fill lands at 6.57:1 (AA + AAA); surface text on the fill drops to 2.61:1 and fails — keep dark text on any accent-filled surface.
